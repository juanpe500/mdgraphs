Quick start

<!-- 1. one script, no dependencies (jsDelivr CDN) -->
<script src="https://cdn.jsdelivr.net/gh/juanpe500/mdgraphs@v1.1.0/mdgraph.js"></script>

<div id="chart" style="height:420px"></div>

<script>
  const player = MDGraph.render('#chart', `
    flowchart LR
      A[Request] --> B{Auth?}
      B -->|yes| C[Handler]
      B -->|no| D[Reject]
      C --> E[(Database)]

      @show A 0.4s
      @flow A->B 1s say:"Incoming request"
      @flow B->C 1s color:#34d399 say:"Authorized"
      @pulse E 0.8s color:#fbbf24
  `, { theme: 'dark', autoplay: true });
</script>

Animation directives

Add @ lines to the source. Each line is one sequential step. Everything is optional except the action and target.

DirectiveWhat it does
@show A,B 0.5sFade & scale nodes/edges into view.
@flow A->B 2sAnimate a glowing particle along the edge (2 seconds).
@flow A->B bothBidirectional flow. Also back for reverse.
@flow A->B color:#f80Custom flow color (hex or CSS name).
@pulse N 0.8sPulse / glow a node to draw attention.
@color N color:#22d3eePermanently recolor a node or edge.
@focus A,BDim everything except the targets. @clear undoes it.
@hide NFade a node/edge out.
@row 0,1Reveal table rows by index.
@show A say:"Any caption"Show a caption for the step (works on any action).

Category icons (Lucide, built in)

Prefix a node label with :icon-name: to stamp a Lucide icon on it — a colored badge that reads as a category. 195 icons are bundled inline (no network requests); the badge takes the node's accent color automatically.

flowchart LR
  A([:user: Client]) --> B{:shield: Auth?}
  B -->|yes| C[:server: API Handler]
  C --> D[(:database: Postgres)]
  C --> E[[:zap: Redis]]

Options: iconPos: 'top' (default badge) or 'inline' (glyph left of the label); iconColor to force one color. Add your own with MDGraph.registerIcons({ name: '<svg inner markup>' }). A few of the bundled names:

Subgraphs (clusters)

Group nodes into labeled containers with subgraph … end — great for "frontend / backend / infra" architecture views.

flowchart LR
  subgraph Frontend
    U[:users: Users] --> W[:globe: Web]
  end
  subgraph Backend
    S[:server: API] --> DB[(:database: DB)]
  end
  W --> S

Sequence diagrams

Start the source with sequenceDiagram. Messages animate one by one — perfect for walkthroughs.

sequenceDiagram
  participant U as User
  participant A as App
  participant S as Server
  U->>A: Click login       // solid arrow
  A->>S: POST /auth
  S-->>A: 200 token         // dashed return
  Note over A,S: cached 15 min

Viewer controls

ControlHow
Zoom & panMouse wheel to zoom, drag to pan; toolbar ＋ － ⤢ or keys + - 0
Export PNG / SVGToolbar 🖼 button, or player.exportPNG() / exportSVG()
Record videoToolbar ⏺ records the animation to a WebM file (player.record())
PresentationToolbar ⛶ or key F for fullscreen with big captions
Play on scroll{ playOnView: true } — animates when scrolled into view
Auto theme{ theme: 'auto' } follows the OS light/dark setting

Motion respects prefers-reduced-motion automatically (shows the final state without animating).

JavaScript API

const p = MDGraph.render(el, source, options);
p.play(); p.pause(); p.toggle();
p.next(); p.prev(); p.seek(3); p.restart();
p.setSpeed(2);
p.on('step', e => console.log(e.index, e.step));
// drive the timeline from code instead of @ directives:
p.animate([
  { action:'flow', targets:'A->B', dur:1500, say:'Step one' },
  { action:'pulse', targets:'B', color:'#fbbf24' }
]);
// viewer:
p.zoomBy(1.2); p.resetView();
p.exportPNG(); p.exportSVG();
p.record();            // -> WebM download
p.toggleFullscreen();
